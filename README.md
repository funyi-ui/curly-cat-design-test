# 고양이 운세 웹사이트 — VS Code 시작 파일

이 프로젝트는 게임과 별도로 관리하는 고양이 운세 웹사이트입니다.
고양이 방 디자인, 마우스·터치 시선 추적, 고양이 인사, 카드 12종, 5개 언어를 포함합니다.
기존 사이트의 방 디자인 버전을 로컬 개발용으로 복사했습니다. 온라인 사이트에는 변경을 가하지 않았습니다.

## 1. 압축 풀기

ZIP 안의 frontend, backend, documents 폴더와 루트 파일들을
C:\Users\hka11\Desktop\meow0930 에 넣습니다.
package.json이 meow0930 바로 아래에 있어야 합니다. meow0930 안에 폴더를 한 겹 더 만들지 마세요.
같은 이름의 폴더는 합칩니다. 이미 파일이 생겼다면 덮어쓰기 전에 백업합니다.

## 2. 실행

VS Code에서 meow0930 폴더를 열고 터미널에서 실행합니다.

```powershell
cd C:\Users\hka11\Desktop\meow0930
npm.cmd run dev
```

브라우저에서 http://127.0.0.1:5173 을 엽니다.
추가 패키지 설치나 npm install은 필요 없습니다. Node.js 기본 기능만 사용합니다.
종료: 터미널에서 Ctrl+C. 수정 후 브라우저를 새로고침합니다. 자동 새로고침 기능은 없습니다.

## 3. 기능 검사

```powershell
npm.cmd test
```

이 검사는 언어 전환, 카드 결과 유지 등 화면 로직을 검증합니다.
실제 브라우저 렌더링 검사는 아닙니다. 아래 동작을 브라우저에서도 직접 확인하세요.

- 고양이 눈동자가 커서를 따라가는지
- 고양이를 클릭하면 인사하는지
- 세 주제에서 카드 선택 및 해석 보기가 되는지
- 다시 섞어 보기와 5개 언어 전환이 되는지
- 언어를 바꿔도 뽑은 카드가 유지되는지
- 새로고침해도 언어 선택이 기억되는지
- 좁은 화면에서 카드와 버튼을 누를 수 있는지

## 4. 폴더 역할

- frontend: HTML, CSS, JavaScript, 이미지, 로컬 미리보기 서버와 기능 검사
- backend: 향후 실제 로그인·AI 호출·데이터 저장을 만들 자리. 아직 구현되지 않음
- documents: 개발 인수인계와 다음 단계
- package.json: 프로젝트 루트에서 실행하는 명령

## 5. 현재 범위

카드 답변은 미리 저장된 해석입니다. 실제 AI 호출, 육효·명리·자미두수 연동,
회원가입, 데이터베이스, 광고, 결제는 포함하지 않습니다.
한국어·영어·인도네시아어·프랑스어·스페인어를 지원합니다.
외부 Google Fonts 연결이 안 되어도 시스템 글꼴로 표시됩니다.

API 키, 실제 회원 질문, 계정 비밀정보는 frontend에 넣지 마세요.
이 서버는 내 컴퓨터에서만 확인하는 미리보기용이며 실제 회원 서비스 운영용 서버가 아닙니다.

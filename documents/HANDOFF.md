# 개발 인수인계

## 유지할 디자인과 동작
- 아이보리 종이 위 흑백 낙서 고양이 방
- 곱슬 장모 고양이, 별 망토, 달 창문, 책·보석 선반, 책상
- 눈동자는 좌우 별도 DOM 요소로 구현; cat.png에는 눈동자가 없는 눈 윤곽이 있음
- 눈동자 중심: 왼쪽 x39.35%, 오른쪽 x61.16%, y39.04%; 임의의 일반 고양이 그림으로 교체 금지
- 카드 ID와 언어별 해석 배열의 순서를 함께 유지할 것
- 질문 주제와 카드 결과는 언어 변경으로 재추첨하지 않음
- 언어만 localStorage에 저장; 회원 기록 저장 기능으로 간주하지 말 것

## 핵심 파일
- frontend/index.html: 고양이 방과 해석 메모 구성
- frontend/style.css: 반응형 스타일, 눈 위치, 책상과 고양이 배치
- frontend/app.js: 추첨, 시선 추적, 언어 전환, 인사
- frontend/i18n.js: 카드 12종과 5개 언어, 방 화면 문구
- frontend/cat.png / room.png: 승인된 이미지
- frontend/tests/i18n.cjs: 가벼운 DOM 모형을 사용하는 기능 검사

## 다음 단계
1. 로컬 실행과 PC·모바일 화면 검증을 먼저 완료.
2. 실제 회원 로그인 방식과 저장소를 선택해 서버에서 회원별 접근 권한을 구현.
3. 질문·답변·삭제·평가와 내 기록장 연결.
4. AI 호출은 서버에서만 수행; 비용·이용량 제한과 오류 처리를 준비.
5. 점술 엔진은 검증된 실제 결과를 AI에 전달. 현재 해석을 엔진 계산 결과라고 표시하지 말 것.
6. 애드센스는 승인·설정 이후에 연결하고 비로그인 상태에서만 로드.

## 배포
이 폴더는 기존 Sites 프로젝트와 연결되지 않은 독립 로컬 개발 사본입니다.
기존 배포 식별자, 소스 원격주소, 인증 토큰은 포함하지 않습니다.
개발 변경은 기존 웹사이트에 자동 반영되지 않습니다. 배포 대상과 방식을 정한 뒤 별도로 배포하세요.

## VS Code AI에게 전달
기존 HTML/CSS/JS 구조를 유지하고 먼저 npm.cmd run dev로 실행한다.
화면 확인을 위해 새 프레임워크를 설치하거나 프로젝트를 다시 생성하지 않는다.
게임 코드를 섞지 않는다. API 키와 비밀정보를 프런트엔드에 넣지 않는다.
회원가입·AI·결제·광고는 실제 연결 전까지 완료됐다고 표현하지 않는다.
